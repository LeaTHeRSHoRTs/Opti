# Opti
A JavaScript browser module, with zero imports

[![npm version](https://img.shields.io/npm/v/optijs.svg)](https://www.npmjs.com/package/optijs)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Features

- Zero specific imports
- New methods on existing objects

## Installation

Installation of the types is recommended, along with the Opti CLI tool.

```bash
npm install optijs
```

Once you have done that, include this code snippet in your HTML code:

```html
<script type="importmap" src="https://cdn.jsdelivr.net/npm/optijs@0.0.3/js"></script>
```

And then include it in your JavaScript or TypeScript files using this:

```js
import 'opti';
```
